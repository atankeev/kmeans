## Language

Use English for public project content: code comments (including GoDoc),
documentation, GitHub issue and pull request titles, descriptions, and comments.
Use the user's preferred language for conversation with the user.

## Git workflow

Before editing repository files, committing, opening a PR, or merging, read and
follow `docs/agents/git-workflow.md`. Deliver changes to `main` through a PR.

## Go style

Before changing Go production code or tests, and before a Standards review of
Go changes, read [the project Go style guidance](docs/agents/go-style.md) and
the pinned Uber Go Style Guide linked there. Apply both to the complete task
diff; explicit project requirements and accepted ADRs take precedence.

## Agent skills

### Issue tracker

Track work and record task plans and agreed decisions in GitHub Issues. Before
planning or updating a task, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage labels without aliases. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain documentation layout. See `docs/agents/domain.md`.
